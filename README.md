PocketInn 是一个基于 Flutter 开发的 AI 聊天应用，偏向角色扮演和沉浸式对话体验，兼容 SillyTavern 的角色卡、世界书、预设等数据格式。

## 功能

- 支持配置多种 AI 接口
- 支持角色聊天与预设管理
- 支持世界书等基础设定功能
- 支持导入本地角色资源
- ✨ 新增：Summaryception 分层金字塔剧情记忆模块

## 开发环境

- Flutter
- Dart 3
